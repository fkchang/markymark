* Not Planned :scope:
:PROPERTIES:
:CUSTOM_ID: not-planned
:END:

These org-mode features are outside MarkyMark's scope as a *reader-only* tool:

- Babel code execution
- Agenda views (requires file aggregation)
- Clock/time tracking (requires state)
- Capture templates
- Archiving
- Export backends
- Org-roam/linking database
- Property inheritance
- Column view

MarkyMark focuses on *rendering documentation*, not *editing workflows*.
